# Cambio 3.2.1 — Ajustes compactos y acceso directo a Mis datos

Este patch mantiene el cambio 3.2.1, pero corrige la UX del engrane:

- El panel de Ajustes ya no abre todas las secciones grandes de golpe.
- Notificaciones, Mis datos y Eliminar cuenta quedan como secciones desplegables compactas.
- En admin, Estadísticas también queda como sección desplegable.
- Desde Inicio, cuando el bloque de Cliente UCAPSA dice “Completa tu perfil”, tocarlo abre Ajustes directamente en Mis datos.
- También se puede tocar el hero superior de cliente incompleto para abrir Mis datos.

No cambia SQL ni envío real de notificaciones.
